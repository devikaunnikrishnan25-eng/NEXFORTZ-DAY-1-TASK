# Day 1 – ESP32 Basic Setup and Blink Test

## Objective

To familiarize myself with the ESP32 development board, upload a basic Blink sketch, and verify the program output through the Serial Monitor.

## Hardware Used

- ESP32 development board
- USB cable
- Computer

## Software Used

- Arduino IDE
- ESP32 Arduino board package

## Procedure

1. Connected the ESP32 development board to the computer using a USB cable.
2. Configured the ESP32 board in the Arduino IDE.
3. Selected the appropriate COM port for the connected ESP32.
4. Created and uploaded a Blink sketch to the ESP32.
5. The onboard LED was programmed to turn ON and OFF at one-second intervals.
6. Opened the Serial Monitor and set the baud rate to **115200 baud**.
7. Verified the messages generated by the ESP32 during the execution of the program.

## Program Description

The Blink program uses GPIO 2 to control the onboard LED.

The `setup()` function:

- Configures GPIO 2 as an output.
- Initializes serial communication at 115200 baud.
- Prints `ESP32 Blink started` to the Serial Monitor.

The `loop()` function:

- Turns the LED ON.
- Prints `LED ON` to the Serial Monitor.
- Waits for one second.
- Turns the LED OFF.
- Prints `LED OFF` to the Serial Monitor.
- Waits for one second.
- Repeats continuously.

## Board Configuration

- **Board:** ESP32 Dev Module
- **Flash Size:** 4MB (32Mb)
- **Partition Scheme:** Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)
- **Flash Frequency:** 80MHz
- **Flash Mode:** QIO
- **PSRAM:** Disabled

## Verification

The ESP32 was successfully programmed and the Blink operation was observed on the hardware.

The Serial Monitor was also verified at **115200 baud**, and the expected `LED ON` and `LED OFF` messages were displayed.
